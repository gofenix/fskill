# 英文写作参考

英文编辑的目标不是“更高级”，而是更自然、更准确、更像真实作者。

## 常见 AI 味

- 过度铺垫："In today's fast-paced world"、"It is important to note"。
- 虚假平衡：句子只需表达一个主张时，却使用 "not only... but also"。
- 用抽象名词替代动作：用 "implementation of improvements" 代替 "improve"。
- 夸大的形容词：robust、seamless、innovative、powerful、comprehensive。
- 每节结尾重复结论。
- 过度使用英文长破折号和括号。改用句子节奏、逗号和句号。
- 过度格式化：正文四处加粗、普通叙述拆成列表、每段都设小标题、能用一句话表达的信息也做成表格。

## 编辑动作

- 删掉没有实质内容的开场句。
- 优先用动词，少堆名词。
- 使用作者的具体名词，不换成泛化标签。
- 短句保持简短。
- 删除不增加新信息的总结句。
- 保持技术术语准确。

## 修改前后

较弱：

```text
This comprehensive solution enables users to seamlessly manage their workflow.
```

更好：

```text
Users can manage the workflow in one place.
```

较弱：

```text
It is important to note that this feature is not only powerful but also easy to use.
```

更好：

```text
This feature is useful because it removes one setup step.
```

## 保留

- 有意保持的技术精确性。
- 作者声音，包括直白或随意的措辞。
- 产品名、命令、路径、代码标识符。
- 证据不确定时必要的保留措辞。

## 输出

粘贴正文的改写只返回改稿，除非用户要求说明。文件交付遵循入口的“匹配交付方式”规则。
