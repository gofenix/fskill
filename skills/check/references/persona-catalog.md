# 审查视角目录

`/check` 默认自己完成审查。只有风险明显匹配时，才按需加载 1 到 2 个补充视角，不固定人数。

| 审查视角 | 何时使用 | 关注点 |
|---|---|---|
| 架构（见 `agents/reviewer-architecture.md`） | 改动跨模块、引入抽象、改数据流或配置 | 边界、复杂度、事实来源、可测试性 |
| 安全（见 `agents/reviewer-security.md`） | 涉及权限、secret、删除、网络、发布、用户输入 | secret 泄露、注入、危险默认值、供应链 |
| 发布 | 涉及版本、tag、package、installer、release asset | 版本一致性、生成物、发布验证、远端状态 |
| 测试 | 修复 bug 或改共享行为但测试薄弱 | 覆盖缺口、回归路径、fixture 真实性 |

使用规则：

- 审查视角只补充发现项，不替代项目上下文提取。
- 公共回复语气与格式对照 `public-reply.md`；通用文案润色属于 `/write`。
- 如果该视角没有发现问题，不要为了填充输出制造意见。
