# 领域逻辑实验

当问题涉及业务事件、状态转换或数据表达能力时读取。产物是一个无需安装依赖即可打开的 HTML 文件，让领域专家用实际操作发现模型里的矛盾。

## 逻辑与页面分开

把回答问题的逻辑放在独立 `<script>` 中，选择符合问题的 reducer、显式状态机或纯函数集合。逻辑接收普通数据并返回结果，不访问 DOM、`document`、按钮或页面全局状态；页面只负责输入和展示。需要持续状态时显式传入、返回状态，避免把转换规则藏进事件处理器。

这样可以在正式实现获授权后提取被验证的逻辑；可提取不代表已经满足生产验证要求。

## 单文件演示

HTML、样式和脚本均内联，不依赖 CDN、框架或服务器；使用领域词汇描述操作和状态。页面依次展示：

1. 要回答的问题、假设及判定标准。
2. 相关状态和最近一次变化，用可读字段说明，不只倾倒 JSON。
3. 可自由尝试的领域操作与重置入口；非法操作给出领域原因，不能静默忽略。
4. 分场景的导引操作：开始场景时重置到确定状态，每步真正触发对应操作，并显示预期观察和实际状态。

选择能够区分假设的正常路径、困难边界和非法操作；不要为了覆盖率堆场景。涉及时间、随机数或外部结果时固定输入并标明替身，让同一场景可重复。

## 验证与交接

实际走过关键场景，核对状态转换和判据。若问题依赖复杂计算或不变量，给纯逻辑增加最小可运行断言；只是让用户体验模型时，不为一次性页面建立测试体系。

交付 HTML 的绝对路径和打开方法，说明实际走过的场景与尚待领域专家判断的问题。正式实现只在已有授权下承接，HTML 外壳与模拟数据保留实验身份。
