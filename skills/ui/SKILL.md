# UI: 带着判断力做界面

首行内联带上 🥷，不要单独起段。

## 交付约定

- 目标: 做出能实际交互、方向感清晰的新界面，或把现有界面截图中的具体体验缺陷修顺。
- 完成条件: 核心操作、受影响页面与状态已在真实渲染中检查；只做评审或方案时交付按影响排序的具体修改点，并说明未验证项。
- 依据: 当前需求、现有设计系统与组件源码、设计变量、可访问性及实际渲染/截图。
- 交付形式: 可跑起来的界面与真实渲染检查说明，或直接可改的设计问题清单。

## 长期上下文预检

先读取 [长期上下文预检](references/durable-context.md)。旧记忆只提供偏好与参考方向；当前截图、渲染状态、项目源码与用户反馈优先于旧记忆。

## 调用边界

仅在用户显式调用 `/ui`、`$ui`、fskill 限定入口或已开启的 `/f-mode` 选中时执行；同一任务里的追问继续沿用，**不自动切换技能**（`f-mode` 开启时除外）。不用于后端逻辑或数据管道；明显是代码回归或渲染报错时建议改用 `/hunt`；文档、PPT 或分页 PDF 建议专用文档工具。只让评审或出方案时只读交付；已有明确修改授权时直接完成修改并验证，先读现有设计系统、组件与图标库（遵循项目已有风格）。

## 视觉红线（反 AI Slop）

涉及具体样式与动效时按需读取 [设计陷阱](references/design-traps.md) 与 [交互与动效](references/design-motion.md)。始终守住这些底线：

- **禁止视觉套壳模板**：不做卡片套卡片，不把正常页面区块做成漂浮卡；不用装饰性 orb / gradient orb / bokeh blob；拒绝单一色相（整页紫、蓝紫、米色、深蓝、棕橙）一把梭。
- **真实视觉资产**：主题驱动页用真实匹配的视觉资产，不用空洞渐变/假 SVG 冒充主视觉；工具软件工作区首屏直达任务，不硬加装饰大图，图标优先现有图标库，无约定时用 lucide，纯图标按钮必须配 tooltip 或可访问标签。
- **排印与布局稳态**：不用 viewport width 直接缩放字号，正文与工具界面 letter spacing 默认 0；长文本不能挤出按钮或卡片，不允许靠缩小字号或 `overflow: hidden` 掩盖溢出。
- **Web 3D 与输出规范**：Web 3D 优先 Three.js（沿用项目既有栈），主场景全幅无框且必须截图检查 canvas 非空与动态效果；所有输出与界面文案不用长破折号（U+2014 / U+2013）。

## 真实验收

遵循 `p-prove-it-works`：改完后在真实界面操作核心流与边界状态（网页过目标断点两侧，原生应用测最小宽/高与正常尺寸），检查长中文/长英文以及加载、空、错误状态；截图或录屏证明非空与不重叠，不拿编译通过顶替视觉验收。
