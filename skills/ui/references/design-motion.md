# 交互与动效

fskill 改写说明：将 Emil Kowalski apple-design 的连续交互方法中文化，补充取消、键盘与现有设计系统边界，省略上游代码和固定参数。来源与许可统一见仓库根目录的 `LICENSE`。

仅在手势、拖拽、抽屉、状态过渡或动效调优相关时读取。优先使用现有组件和平台能力，不为应用这些方法自动安装动画库，也不默认把产品改成 Apple 视觉风格。

## 反馈等到动作结束

按下时即可呈现反馈，操作提交仍遵循现有点击、松开、取消与键盘语义。不能把即时反馈误实现为按下就执行不可逆操作。拖动期间持续跟随输入，保留抓取偏移，不在松手时才补一段动画。

Web 自定义拖拽需要适当的 Pointer Capture，以及 `pointercancel`、丢失捕获和卸载清理；与页面滚动及其他手势协调。原生界面优先使用平台手势和控件语义。

## 过渡锁住输入

反复开关、拖动或反向操作时，从当前屏幕位置继续；支持中途改变目标，避免跳到上一目标值后重新开始。不要仅为等动画结束禁用输入。

从拖动转为自动运动时衔接释放速度，并结合动量选择合理停靠点。核对所用 API 的速度单位与重定向行为，不照搬别的库的参数。需要物理响应时选择可重定向、可保持连续性的实现；普通状态反馈无需强行使用弹簧。

弹簧默认平稳收敛，轻微回弹只用于有动量依据的手势或明确的设计语言，不给每个菜单和按钮添加弹跳。进入、退出与触发位置的空间关系应一致，避免用户失去对象去向。

## 材质替代层级

透明、模糊和阴影服务结构与遮挡关系，遵循现有设计系统，不让所有区域都变成玻璃层。复杂背景与叠层下核对文字可读性；字体、字距和行高以项目及语言实际渲染为准，不机械照搬 Apple 示例。

## 减少动态等于没有反馈

尊重平台减少动态效果的设置，Web 使用 `prefers-reduced-motion`：以静态状态或温和淡变替代大位移、视差和弹跳，仍保留状态反馈。透明度和对比度偏好在支持的平台提供对应降级。自定义交互保留键盘操作、可见焦点及与任务匹配的焦点管理。

## 单帧验收动效

验证完整输入到结果的过程：拖到中途反向、松手、连续开关、取消手势，以及适用的键盘和减少动态模式。用实际操作、连续录制或可用的浏览器轨迹检查跳变、延迟和状态卡死；静态截图与代码阅读无法单独证明连续交互质量。性能疑点用实际工具测量，不从使用了 `transform` 推断帧率达标。
