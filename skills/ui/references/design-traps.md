# 设计陷阱

常见界面与 CSS 失败做法及替代方案。

| 陷阱 | 更好的做法 |
|---|---|
| 纯图标按钮缺少可访问名称 | 所有图标按钮配 tooltip 或可访问标签，不熟悉图标加文字 |
| 文字挤不下就缩小字号 | 改布局、换行、给稳定宽度，或精简确有冗余的废词 |
| 状态切换改字号 | 保持字号稳定，用字重、颜色、边框、图标区分 |

CSS 注意：

- 避免 `height: 100vh` 导致移动端地址栏问题，优先 `min-height: 100dvh`。
- 固定工具栏要考虑安全区域。
- `overflow: hidden` 不能用来掩盖实际溢出。
- grid/flex 子项需要 `min-width: 0` 才能正确收缩。
- 绝对定位文本要检查窄屏和长文案。
