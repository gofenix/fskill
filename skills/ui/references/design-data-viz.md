# 数据可视化

数据可视化先服务比较和判断，再服务美观。

## 选择图表

| 目标 | 图表 |
|---|---|
| 比较类别 | 条形图 |
| 看趋势 | 折线图 |
| 看组成 | 堆叠条形图，少用饼图 |
| 看分布 | 直方图、箱线图 |
| 看相关 | 散点图 |
| 看流程或路径 | 桑基图、流程图、时间线 |

## 规则

- 坐标轴、单位、时间范围必须可见。
- 颜色用于含义，不用于装饰。
- 同一页面里的同一指标使用同一颜色。
- 不截断 y 轴，除非明确标注。
- 图例靠近数据，避免用户来回扫。
- 主要问题应无需展开就能回答；移动端优先展示最关键序列，仅将补充记录折叠或切换。稀疏和典型数据都要检查，不用无意义内容填空。

## 文案

标题写结论，不写图表类型。例如“错误率在 3 月后下降”，不要写“错误率折线图”。

## 验证

检查空数据、单点数据、极长标签、负数、单位混合和色盲可辨性。
