# 中文去 AI 味模式库

这是气味参考，不逐条机械替换；先合并归类，不追加同义词。

- **空泛开场与总结腔**：删“在当今快速发展的时代”“随着技术不断进步”“值得注意的是”“总的来说”“从某种意义上说”“本质上”“不是 A，而是 B”“先 A，再 B”。如果只是重复上一段就整句删掉；只保留有新信息的具体判断并带出具体对象。
- **抽象名词与空形容词**：把“全面优化体验”“能力建设”“流程闭环”“显著/极大/丝滑/赋能”改成具体动作或可观察结果。
- **复读表格与元叙事**：正文别逐行复读表格，表头已写类别时条目不再带后缀词；删掉“按三段拆”“本文不谈什么”这类讨论写法的元话语；少用伪口语口号（直接点名文件、动作与结果）。
- **过度排版与节奏均等**：正文靠句子自身节奏强调，少用 `**加粗**`、每段小标题、大段列表装饰与长破折号（U+2014 / U+2013）/ 括号插注；连续段落如果全是“观点 + 解释 + 小结”且长度均匀，主动打散。
- **中英混排与标点**：中英文词间加空格（反引号内命令/路径除外）；清楚的英文术语不生硬硬译；中文用全角引号 “ ” 和 ‘ ’；首提陌生人名需交代身份（作者明说不要人物背景则直接删名）。
- **中文发布说明**：按条目写清楚这次具体改变了什么和为什么（例如 `5 到 8 条足够，除非发布规模很小或很大`），只用具体改动说明，不要写“全面优化体验”这类空话，也别照抄上一版的条目配额；风格保持工程师可读，不做营销腔。
- **输出纪律**：粘贴文本只交改稿，删完 AI 尾注与“希望对你有帮助”；只有要求审稿或给多版本时才附简明结论（多版本最多 3 个）。
