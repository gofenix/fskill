# 英文写作参考

目标不是“更高级”，而是自然、精确、像真人写的英文。

- **删掉套路信号**：删 “In today's fast-paced world”、“It is important to note”、无依据的 “not only... but also...”、空洞形容词（robust、seamless、innovative、powerful、comprehensive），以及每节结尾复读结论。
- **动作替代抽象名词**：用具体动词（“manage the workflow in one place”）代替名词堆砌（“enable seamless workflow management”）。
- **禁用 U+2014 / U+2013 与过度装饰**：不用英文长破折号和括号插注，少用散落加粗或把普通叙述拆成列表与小标题。
- **保留与输出**：保留技术精确性、代码/命令标识、作者原本的直白口吻及诚实的限制措辞；改写正文默认只交付改稿。
