# fskill 路由

fskill 提供 10 个工作技能，以及 f-mode 路由和 f-help 使用指南。未开启 f-mode 时，用 `/name` 或 `$name` 调用技能。显式输入 `/f-mode` 后，为当前会话开启路由；`/f-mode off` 关闭路由，`/f-mode status` 查询状态。直接命令优先，不改变 f-mode 的开关。新会话默认关闭路由。相似词或引用的命令不会开启 f-mode。路由前先读取 f-mode，只加载选中的技能。路由不扩大操作权限。更细的做法在选中技能的模式里，不再各占一条命令。

| 技能 | 使用场景 |
|---|---|
| f-mode | 显式控制会话路由，或开启后按目标选择技能 |
| f-help | 了解 fskill 用法、选择技能，或询问安装与定制 |
| catchup | 只读核对进展、变化、阻塞和待用户决定的事项 |
| think | 计划、术语、跨会话路线、切片、一次性实验、代码边界、校准后按授权完成，或协调已批准的任务图。普通代码修改由当前 Agent 直接做 |
| hunt | 已有故障时先证明根因；指标已经定时一次只试一个假设 |
| check | 审查 diff、规格、发布和项目代码体检，处理 issue 或外部 PR 队列，并维护可复用的验证指南 |
| ui | 构建页面、组件，并按截图打磨视觉 |
| learn | 研究陌生领域、代码库或决策历史，或读取一份 URL 或 PDF |
| write | 改写文案，去掉 AI 味 |
| handoff | 交接或恢复当前会话 |
| retro | 记录经过验证、能改变下次做法的经验 |
| health | 审计 Agent 配置、指令漂移、hooks 和验证入口，并指导必须由人完成的配置或迁移 |

两个技能都匹配时，读取各自 `SKILL.md` 的排除范围。仍无法判断，再询问用户。
